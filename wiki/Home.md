# 🎓 Template Tugas Akhir Poliwangi

**Template LaTeX siap pakai untuk Proposal & Laporan Tugas Akhir —**
**Politeknik Negeri Banyuwangi (Poliwangi)**

*Tulis Tugas Akhir sekali, jadi dokumen rapi untuk Proposal maupun Laporan.*

---

## 📌 Apa ini?

Repository ini berisi template LaTeX untuk menulis **Proposal Tugas Akhir** dan
**Laporan Tugas Akhir** di Politeknik Negeri Banyuwangi. Seluruh aturan format
diambil langsung dari **Pedoman Mutu Tugas Akhir Poliwangi 2023** (Bab 6 +
Lampiran 1–12), jadi mahasiswa tidak perlu mengatur format secara manual —
cukup menulis isi penelitian.

## ☁️ Belum punya LaTeX? Pakai Overleaf

Klik tombol di bawah untuk langsung membuka seluruh isi repo ini sebagai
project Overleaf — sekali klik, tanpa pasang apa pun:

**→ https://www.overleaf.com/docs?snip_uri=https%3A%2F%2Fgithub.com%2Fvianziro%2FTemplate-Latex-Poliwangi%2Farchive%2Frefs%2Fheads%2Fmain.zip**

Setelah masuk ke editor Overleaf:

1. pilih `proposal/proposal.tex` atau `laporan/laporan.tex` di daftar berkas
2. pastikan compiler **pdfLaTeX** (Menu → Settings → Compiler)
3. tekan **Recompile** — PDF langsung jadi

Kalau tombol tidak jalan (misalnya belum login Overleaf), buka halaman
[Mulai Cepat](Mulai-Cepat) untuk cara manualnya.

## 🚀 Lima langkah singkat

```text
1. Buka proposal/proposal.tex  atau  laporan/laporan.tex
2. Isi identitas di a0-identitas.tex
3. Tulis isi bab di b1-bab1.tex sampai b5-bab5.tex
4. Tambah referensi di a9-pustaka.bib
5. Kompilasi dua kali — selesai, PDF siap dicetak
```

Detail tiap langkah ada di halaman **[Mulai Cepat](Mulai-Cepat)**.

## ✨ Kenapa pakai template ini?

- 📄 **Dua dokumen terpisah** — folder `proposal/` dan `laporan/` yang mandiri
- 🧭 **Format pasti sesuai pedoman** — margin, huruf, spasi, penomoran, halaman awal
- 🧩 **Contoh siap ditiru** — setiap bab berisi contoh tabel, gambar, rumus, diagram alir, grafik, dan kode
- 📚 **Daftar pustaka otomatis** — tulis di `.bib`, sitasi gaya APA
- 🔢 **Penomoran otomatis** — bab, sub-bab, tabel, gambar, rumus, dan lampiran
- 🎨 **Sampul berwarna sesuai prodi** — diganti dari satu baris
- 💻 **Jalan di mana saja** — Windows, macOS, Linux, dan Overleaf
- 🆓 **Lisensi MIT** — bebas dipakai dan disesuaikan
